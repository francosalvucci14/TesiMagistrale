## Idea

[

]

[

]

[
deg(v)\geq k
]

Poi osservi come il core evolve nel tempo.

Una community stabile è un gruppo di nodi che:

* appartiene allo stesso k-core
* per molti snapshot consecutivi
* con poche variazioni

Esempio:

```

A-B-C-D

   E
```

[

\frac{\sum_t |C_t \cap C|}

# Opzione B — Approximate Stable Communities con MinHash + LSH

Questa è più orientata ad algoritmi scalabili.

L'idea:

Il problema principale del paper è la similarità strutturale.

Probabilmente calcola:

[
sim(u,v)
========

\frac{|N(u)\cap N(v)|}
{|N(u)\cup N(v)|}
]

cioè Jaccard.

Il problema:

se hai:

[
|V|=1M
]

hai:

[
O(n^2)
]

confronti.

---

# 1. Idea

Usare MinHash.

Ogni nodo:

```
A:

neighbors:

{2,5,7,9,20}
```

diventa una signature:

```
A:

[13,98,44,72,...]
```

La proprietà:

[
P(h(A)=h(B))
============

J(A,B)
]

quindi:

la probabilità che due signature siano uguali è la similarità.

---

# 2. Locality Sensitive Hashing

MinHash da sola non basta.

Usi LSH.

Esempio:

```
signature:

[3,8,2,7,9,1]


divide:

band 1:

3,8


band 2:

2,7


band 3:

9,1
```

Se due nodi finiscono nello stesso bucket:

sono candidati.

Quindi:

invece di:

```
A confronta B,C,D,E,F...
```

fai:

```
A confronta solo:

B,C
```

# Codice

```python
import networkx as nx
from dataclasses import dataclass, field
from typing import List, Set


# -------------------------------------
# Rappresentazione di una community
# -------------------------------------

@dataclass
class TemporalCommunity:
    id: int
    nodes: Set
    start: int
    end: int

    history: List[Set] = field(default_factory=list)

    def lifetime(self):
        return self.end - self.start + 1



# -------------------------------------
# Jaccard similarity
# -------------------------------------

def jaccard(A, B):

    if len(A) == 0 and len(B) == 0:
        return 1.0

    return len(A & B) / len(A | B)



# -------------------------------------
# Estrazione k-core communities
# -------------------------------------

def extract_kcore_communities(G, k):

    """
    Calcola il k-core e restituisce
    le componenti connesse.

    Ogni componente è una community.
    """

    core = nx.k_core(G, k=k)

    communities = []

    for component in nx.connected_components(core):
        communities.append(set(component))

    return communities



# -------------------------------------
# Dynamic Core Tracker
# -------------------------------------

class DynamicKCoreDetector:


    def __init__(
            self,
            k=2,
            similarity_threshold=0.5):

        self.k = k
        self.threshold = similarity_threshold

        self.next_id = 0



    def detect(self, snapshots):

        """
        snapshots:
            lista di grafi networkx

        esempio:

        [
          G1,
          G2,
          G3
        ]

        """

        active = []

        finished = []



        for t, G in enumerate(snapshots):


            print(f"Processing snapshot {t}")


            communities = extract_kcore_communities(
                G,
                self.k
            )


            matched = set()


            new_active = []



            # confronto con comunità precedenti

            for old in active:


                best_match = None
                best_score = 0



                for idx,new_nodes in enumerate(communities):

                    if idx in matched:
                        continue


                    score = jaccard(
                        old.nodes,
                        new_nodes
                    )


                    if score > best_score:
                        best_score = score
                        best_match = idx



                if (
                    best_match is not None
                    and best_score >= self.threshold
                ):

                    nodes = communities[best_match]


                    old.nodes = nodes
                    old.end = t
                    old.history.append(nodes)


                    matched.add(best_match)

                    new_active.append(old)


                else:

                    # community terminata

                    finished.append(old)



            # nuove comunità

            for idx,nodes in enumerate(communities):

                if idx not in matched:

                    c = TemporalCommunity(
                        id=self.next_id,
                        nodes=nodes,
                        start=t,
                        end=t,
                        history=[nodes]
                    )

                    self.next_id += 1


                    new_active.append(c)



            active = new_active



        # aggiungo quelle ancora vive

        finished.extend(active)


        return finished



# -------------------------------------
# Filtering stable communities
# -------------------------------------

def stable_filter(
        communities,
        min_lifetime=3):

    return [
        c for c in communities
        if c.lifetime() >= min_lifetime
    ]

    communities = detector.detect(
        snapshots
    )


    stable = stable_filter(
        communities,
        min_lifetime=2
    )


    print("\nStable communities:")


    for c in stable:

        print(
            f"""
Community {c.id}

Nodes:
{c.nodes}

Interval:
[{c.start},{c.end}]

Lifetime:
{c.lifetime()}
"""
        )
```

# Però: questa è una versione "baseline"

Per una tesi la migliorerei in 4 punti.

## 1. Dynamic k-core vero

Questo ricalcola tutto:

```python
nx.k_core(G)
```

ogni snapshot.

In una tesi puoi proporre:

* aggiornamento incrementale del core
* solo nodi coinvolti negli edge update

Complessità:

da:

[
O(T(|V|+|E|))
]

a:

[
O(\Delta E)
]

dove (\Delta E) sono gli archi modificati.

---

## 2. Community matching più intelligente

Ora uso:

[
Jaccard(C_t,C_{t+1})
]

ma puoi sostituire con:

[
score=
\alpha Jaccard
+
\beta Density
+
\gamma CoreLevel
]

---

## 3. Evolution graph esplicito

Creerei un DAG:

```
C0(t0)
 |
C0(t1)
 |
C0(t2)


C1(t1)
 |
C1(t2)
```

e poi fai:

* longest path
* persistent components

---

## 4. Gestione split/merge

Ora supporta solo:

```
A ---> A
```

ma nei grafi reali hai:

split:

```
A
|
+--B
+--C
```

merge:

```
A
 \
  C
 /
B
```

Questo sarebbe un contributo interessante.
